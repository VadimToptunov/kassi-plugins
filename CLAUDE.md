# Engineering principles

Hard rules for this repo; follow them unless the user overrides in the moment.

1. **Depth before breadth.** One proven engine, then many surfaces over it. Finish and *list* each plugin before starting the next — no half-built parallel plugins.
2. **Every generator/validator has a validity test anchored to an EXTERNAL published reference.** A value computed with the same algorithm is a circular anchor and does NOT count. A generator without a passing, externally-anchored validity test is incomplete.
3. **Ship discipline.** Branch → PR → CI green → merge for code; `verifyPlugin` / `runPluginVerifier` must report Compatible; prefer non-deprecated IntelliJ Platform APIs; never commit private/strategy docs to this public repo; never add AI attribution ("Generated by Claude Code" / "Co-Authored-By: Claude") anywhere.
